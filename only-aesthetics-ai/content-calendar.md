# Only Aesthetic — Weekly Content Calendar

| Day | Format | Intent |
|-----|--------|--------|
| Monday | Reel | Product motion / glow / chime moment |
| Tuesday | Carousel | Features, materials, styling tips |
| Wednesday | Story | Behind-the-scenes / poll / soft CTA |
| Thursday | Reel | Lifestyle placement / “in a real home” |
| Friday | UGC | Customer clip / remixed lifestyle |
| Saturday | Mood Board | Palette, textures, room inspiration |
| Sunday | Founder Story | Values, craft, why this object |

## How to use with Cursor
Prompt:
> Generate this week’s Only Aesthetic content calendar for [product name]. Follow `content-calendar.md`.

Cursor should output for each day:
- Hook / title
- Visual concept
- Caption draft
- CTA
- Hashtag cluster
- Asset checklist (image/video needed)
