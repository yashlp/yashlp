# PlacePulse

**PlacePulse** is a community intelligence platform that helps people understand, monitor, and improve the places around them.

> Every place has a pulse. PlacePulse helps the community measure it.

## Documentation

The master product specification lives in [`PlacePulse_Master_PRD.md`](./PlacePulse_Master_PRD.md).

This is a living document delivered in parts. Part 1 (Product Vision & Core Concept) is complete; subsequent sections cover user journeys, incident verification, AI features, health scoring, monetization, technical architecture, and security.

## Internal positioning

PlacePulse is **not** a civic reporting app. It is a **community intelligence platform**—a living digital profile for every street, neighborhood, city, state, and country.
