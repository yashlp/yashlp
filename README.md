# Loci — The Community Intelligence Platform

> _Every place has a story. Loci helps the community tell it._

**Loci** (pronounced *LOW-sy*, the Latin plural of *locus*, "places") is an AI-powered
community intelligence platform that turns everyday local observations into trusted,
community-verified intelligence about every street, neighborhood, city, state, and country.

- 📄 **Master specification:** [`Loci_Master_PRD.md`](./Loci_Master_PRD.md)

The master PRD documents every major system — home map, incident & verification, AI
features, Community Health Score, trends/rankings/compare, categories & positive signals,
monetization, technical logic, and security & anti-fraud — using a consistent
**Purpose / User Flow / System Flow / Decision Logic / Edge Cases** structure so it can be
handed directly to engineers, designers, and AI coding tools.
